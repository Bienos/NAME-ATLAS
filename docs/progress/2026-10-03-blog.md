## Changed

- **Posts and parser.** `apps/web/src/lib/blog.ts` parses `apps/web/src/content/blog/<slug>.<lang>.md`: a `---` header with exactly `title`, `description`, `date`, `slug` and `lang`; a body of `##`/`###` headings, paragraphs and `-` lists with `**bold**`, `*emphasis*`, `` `code` `` and `[text](address)`. Links keep only `/path`, `https://`, `http://` and `mailto:` addresses. Any broken rule throws, naming the file. No dependency added. `blog-posts.ts` reads the folder (every `.md` but `README.md`), newest first; a missing folder is no posts.
- **Pages.** `blog-page.tsx` holds `BlogIndexView`, `BlogPostView`, `blogIndexMetadata`, `blogPostMetadata` and `articleJsonLd`. The routes are `app/pl/blog/page.tsx`, `app/en/blog/page.tsx` and `app/{pl,en}/blog/[slug]/page.tsx`, all `force-dynamic`. A slug with no post in the page's language calls `notFound()`. Everything renders as React elements, so HTML in a post is shown as text.
- **Search engines.** Canonical address, `hreflang` only for languages that exist, `robots` `index` only when `SEO_INDEXING_ENABLED` is `true`, `openGraph` type `article` with `publishedTime` and the brand cover, and `Article` JSON-LD (no author; `<` escaped). `/sitemap-blog.xml` (new route) lists posts with `lastmod` and `hreflang` pairs, 404 unless the flag is on, `SITE_ORIGIN` set and a post exists. `/sitemap.xml` passes it to `sitemapIndexXml`'s new optional `extra` argument on the same terms; without it the index is unchanged.
- **Footer.** `followLinks`'s Blog entry leads to `/pl/blog` or `/en/blog`; Instagram, TikTok and YouTube still lead home (`site-links.ts`, `blogPath`, `blogPostPath`). `offer-page.test.ts` updated to match.
- **Other.** Five UI keys per language in `messages.ts`; blog rules in `globals.css`; `next.config.ts` traces `./src/content/blog/*.md` for the blog routes, `/sitemap.xml` and `/sitemap-blog.xml`; `content/blog/README.md` documents the format.
