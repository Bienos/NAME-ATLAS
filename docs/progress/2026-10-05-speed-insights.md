## What changed

- `apps/web/package.json`, `pnpm-lock.yaml`: `@vercel/speed-insights` 2.0.0, pinned (the latest on npm on 2026-10-05). It is the package Vercel's panel names; no other dependency was added.
- `apps/web/src/lib/site-analytics.tsx`: `SiteSpeedInsights`, rendered in `app/layout.tsx` after `SiteAnalytics`. `beforeSend` is now generic over any event with a `url`, so Web Analytics and Speed Insights share it, and each measurement's address goes through `analyticsUrl` (slug → `[slug]`, tree and person ids replaced, query and hash dropped). `speedInsightsRoute` redacts the route as well. Why the route needs its own step, from Vercel's script (`va.vercel-scripts.com/v1/speed-insights/script.js`, read 2026-10-05): the script applies `beforeSend`'s `url` but takes `route` from the script tag's `data-route`, not from `beforeSend`. The route comes from `computeRoute(usePathname(), useParams())`, which gives `/pl/nazwisko/[slug]` only when the path and the param match as strings. A slug keeps its Polish letters (`canonicalSlug`), so when one side is percent-encoded and the other is not, `computeRoute` returns the path itself, surname included. `SiteSpeedInsights` therefore uses `@vercel/speed-insights/react` with that redacted route, plus the base path and configuration the `/next` wrapper reads (`NEXT_PUBLIC_VERCEL_OBSERVABILITY_BASEPATH`, `…_CLIENT_CONFIG`, Vercel's "resilient intake"). The `/next` wrapper takes no `route`.
- `apps/web/src/lib/legal-text.ts` (both languages): the summary names Speed Insights. A new paragraph covers what it records (address and pattern, the measurement and the element it concerns, time, connection type, browser, device type, OS, country), no cookies, not tied to a visitor or IP "as Vercel states", and the surname's removal. Under "How long": Vercel shows the measurements for the last 7 days, and its documentation does not say how long it keeps them. The Vercel processor line now names Speed Insights. `LEGAL_UPDATED.privacy` was already 2026-10-05. `legal-accounts.ts`: the same summary sentence in the accounts variant.
- Tests: `analytics-path.test.ts` (a `vital` event through `beforeSend`; `speedInsightsRoute` for matching params, the tree's catch-all, an empty optional catch-all, a mismatched encoding and no params), `legal-page.test.ts` and `legal-accounts.test.ts` (the notice's new text in both languages and both variants).
- `docs/DECISIONS_NEEDED.md` D-037: Speed Insights is in the same art. 399 position as Web Analytics, and the stale line reference is refreshed. `docs/CODEMAP.md`, `STATUS.md`.
